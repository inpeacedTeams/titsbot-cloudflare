# Mini App: интерфейс набора и графики

Обновление сентября 2026: самостоятельный интерфейс в стиле Monkeytype, с брендингом TitsBot. Это не копия всех функций Monkeytype: режимы, длительность, количество попыток и правила оценки остаются правилами D-калибровки.

## Обновление работающего бота

В локальной папке проекта:

```bat
git pull origin main
npm run check
npm test
npm run deploy
```

Если Git сообщает о конфликте, остановитесь и сохраните локальные настройки; не используйте `git reset --hard`. Обновление интерфейса не меняет `wrangler.jsonc` и секреты. SQL-миграция не нужна: посекундные данные записываются в существующее JSONB-поле metrics.

После деплоя полностью закройте Mini App и откройте заново из персональной кнопки `/getdmt` в разрешённой группе. Настройки BotFather, webhook и PUBLIC_URL менять не требуется.

## Что изменилось

- Фиксированная тёмная тема, моноширинный текст и жёлтая каретка.
- Клик или касание области текста запускает попытку с отсчётом 3–2–1; поддерживается клавиатурная активация кнопки.
- Ввод непосредственно поверх текста, подсветка правильных символов и подчёркивание ошибок, Backspace, автоматический сдвиг строк.
- Предварительные WPM и accuracy во время набора.
- Экран результатов с WPM, raw WPM, accuracy, consistency, символами, ошибками, исправлениями и Score.
- График WPM/raw по секундам и отдельная полоса ошибок за секунду, точные значения при наведении, раскрываемая таблица.
- Просмотр каждой из трёх попыток и выделение лучшего Score.
- Адаптация к узким экранам, видимый клавиатурный фокус, текстовая альтернатива графику, reduced-motion.

## Честные графики

`mtMetrics` сначала проверяет события, затем вычисляет 30 наблюдений `timeline`. На секунде t WPM равен оставшимся правильным символам / 5 / (t / 60), raw WPM — всем вставленным символам / 5 / (t / 60). Это накопительная средняя, а не мгновенная скорость. Ошибки показываются за отдельную секунду. Последние значения WPM/raw совпадают с итоговыми метриками; сумма ошибок на графике совпадает с общим числом ошибок. Исправления и удаления учитываются.

Графики появляются у попыток, закрытых новой версией сервера. Результаты старых попыток не изменяются: если timeline отсутствует, интерфейс прямо сообщает об отсутствии графика. Старые D и потраченные попытки не сбрасываются.

## Ограничения сохранены

Три попытки по 30 секунд. Кнопка «следующая попытка» только возвращает к экрану старта; новый клик по тексту расходует попытку. Перезагрузка не даёт бесплатного повтора. Вставка, IME, автозамена, сворачивание или скрытие страницы по-прежнему приводят к нулевому Score. Отключите автозамену на мобильной клавиатуре; аппаратная клавиатура предпочтительнее. Потеря фокуса без скрытия окна не останавливает таймер, клик возвращает фокус.

Учётные записи Monkeytype, рейтинги, темы, произвольные режимы и replay в это обновление не включены.

## Проверки

24 unit-теста (включая три регрессии timeline) и синтаксические проверки пройдены локально. В изолированном браузере с mock API проверены 320/390/1440 px, запуск одним кликом, отсчёт, блокировка раннего ввода, Backspace, отправка событий, запрет вставки, таблица и переход к следующей попытке без её расхода. Превью используют только тестовые данные, не настоящие результаты пользователей. Настоящий Telegram WebView, мобильная клавиатура и production-подключение проверяются после деплоя.
